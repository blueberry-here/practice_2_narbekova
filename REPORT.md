### 2. Установка зависимостей
- **Прямые зависимости и их назначение:**
  - `requests` — для выполнения HTTP-запроса к API Open-Meteo.
  - `matplotlib` — для визуализации данных (построения графика).
  - `pandas` — для структурирования данных в DataFrame и сохранения в CSV.
- **Почему `numpy` не является прямой зависимостью:** В исходном коде нет прямого импорта `numpy`. Он устанавливается автоматически как транзитивная зависимость, необходимая для работы `pandas` и `matplotlib`.
- **Команда установки:** `pip install requests matplotlib pandas`
- **Результат запуска:** Программа завершилась без ошибок. Создан файл `temperature_24h.csv`, содержащий заголовок `time,temperature_c` и 24 строки данных. Построен график температуры.
