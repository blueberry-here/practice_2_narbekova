### 6. Доработка программы
В файл `plt_temp.py` внесены следующие изменения для повышения надёжности и тестируемости:
- **Ограничение времени ожидания:** в `requests.get` добавлен параметр `timeout=10`.
- **Проверка HTTP-статуса:** добавлен вызов `response.raise_for_status()` до попытки чтения JSON, чтобы сетевые ошибки не маскировались под ошибки парсинга.
- **Выделение функции:** логика преобразования списков времени и температуры вынесена в отдельную функцию `process_temperature_data(hours, temps)`. Она принимает данные через аргументы и не выполняет сетевых запросов, что позволяет легко тестировать её изолированно.
- **Сохранение графика:** добавлен вызов `plt.savefig("temperature_24h.png")` для сохранения визуализации в файл (вместо или вместе с `plt.show()`).
- **Результат:** при запуске программа успешно создаёт оба файла (`temperature_24h.csv` и `temperature_24h.png`), а структура кода позволяет проводить модульное тестирование.

### 8. Работа с группами
**Вариант 1: `poetry install --without dev,test`**
- **Установлены:** только основные зависимости (`requests`, `matplotlib`, `pandas` и их транзитивные зависимости, всего 18 пакетов).
- **`pytest`:** не установлен в окружении (выведенная версия 8.4.2 принадлежит глобальной установке в системе, в логе установки Poetry его нет).
- **`ruff`:** недоступен (ошибка "не является внутренней или внешней командой").
- **Скрипт запускается:** да, успешно создал `temperature_24h.csv` и `temperature_24h.png`.
- **Причина:** флаг `--without` исключает указанные группы из процесса установки, оставляя только базовые зависимости из `[tool.poetry.dependencies]`.
**Вариант 2: `poetry install --only test`**
- **Установлены:** только группа `test` (`pytest` и его зависимости, всего 6 пакетов).
- **`pytest`:** доступен (версия 9.2.0).
- **`ruff`:** недоступен (ошибка "не является внутренней или внешней командой").
- **Скрипт запускается:** нет, завершается с ошибкой `ModuleNotFoundError: No module named 'requests'`.
- **Причина:** флаг `--only` устанавливает *исключительно* указанную группу, полностью игнорируя основные зависимости из `[tool.poetry.dependencies]`.
**Вариант 3: `poetry install` (полное окружение)**
- **Установлены:** все группы (основные зависимости + `test` + `dev`).
- **`pytest`:** доступен (версия 9.2.0).
- **`ruff`:** доступен (версия 0.17.3).
- **Скрипт запускается:** да, успешно создал `temperature_24h.csv` и `temperature_24h.png`.
- **Тесты проходят:** да (`1 passed`).
- **Причина:** команда `poetry install` без дополнительных флагов устанавливает все зависимости, описанные в `pyproject.toml`, обеспечивая полноценное рабочее окружение для разработки и тестирования.
